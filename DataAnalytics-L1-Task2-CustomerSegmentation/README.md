# Customer Segmentation Analysis

## Objective
Segment e-commerce customers into distinct groups based on purchasing behaviour using K-Means clustering.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset inspection and data cleaning
- Missing and inconsistent data handling
- RFM feature analysis
- Feature standardisation using StandardScaler
- K-Means clustering
- Elbow Method for optimal number of clusters
- Cluster visualisation
- Customer segment profiling
- Customer count by cluster
- Marketing recommendations

## Customer Segments
The analysis identifies customer groups based on Recency, Frequency and Monetary behaviour and provides targeted marketing recommendations for each segment.

Customer Segment Insights
Cluster 0 — Regular / Potential Customers

Recency: 43.70 days
Frequency: 3.68 purchases
Monetary: 1353.63
Marketing Action: Use cross-selling, product recommendations and targeted promotions.

Cluster 1 — At-Risk Customers

Recency: 248.88 days
Frequency: 1.55 purchases
Monetary: 478.85
Marketing Action: Run reactivation campaigns, discounts and personalised reminders.

Cluster 2 — High-Value Customers

Recency: 7.38 days
Frequency: 82.54 purchases
Monetary: 127187.96
Marketing Action: Reward with loyalty benefits, premium offers and exclusive products.

Cluster 3 — Regular / Potential Customers

Recency: 15.50 days
Frequency: 22.33 purchases
Monetary: 12690.50
Marketing Action: Use cross-selling, product recommendations and targeted promotions.

Key Findings

Cluster 2 represents the highest-value customer segment with the highest purchase frequency and monetary value.
Cluster 1 contains at-risk customers who have not purchased recently and may require reactivation campaigns.
Clusters 0 and 3 represent regular/potential customers who can be targeted through cross-selling and personalised promotions.

Conclusion
The customer segmentation analysis successfully groups customers based on Recency, Frequency and Monetary (RFM) behaviour using K-Means clustering. The identified segments can help businesses design targeted marketing strategies and improve customer retention.
